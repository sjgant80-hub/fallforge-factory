How the factory runs itself

  1. Every layer is proved the same way. Each kernel is mutation-witnessed; survivors carry a written equivalence argument. The factory manifest binds all five kernel hashes and gate scores into one content-addressed record.
  2. The proof composes. A node minted by the mint carries the gate's receipt; the catalogue shelves that exact manifest; the mesh couples that exact node. One hash chains all four — this page checks it live.
  3. A demand it can't serve is an opening, not a lie. The seam routes a covered use-case to its node and flags an uncovered one for minting — the factory never invents a specialist it lacks.
  4. The money rail stays human. The whole node/compute rail is buildable and built; licensing and payments wait behind legal counsel. Nothing here bills anyone.

The honest limits

  • v1 mints prompt-tuned nodes (Modelfile-level); weight-level LoRA is v2, in the same gated stages.
  • Signatures prove the issuer's key, not their identity; receipts and savings are scoped to their probe set and the buyer's own rates.
  • This capstone is a public composition surface — not the estate's private orchestrator. It proves the factory chain; it does not run anyone's private mesh.
  • Not audited. Five kernels, five gates, one chain — proof of construction, not a security certification.
